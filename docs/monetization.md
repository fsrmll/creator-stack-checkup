# Monetization

The core app is free and open source. Monetization should not block basic use.

## Good Monetization Options

1. Ko-fi support
   - support development
   - request tool presets
   - fund new features

2. Gumroad support pack
   - extra creator tool presets
   - monthly review PDF
   - creator finance checklist
   - Notion/CSV templates

3. GitHub Sponsors
   - add after the project has public traction

4. Future Pro version
   - optional cloud sync
   - email reminders
   - team stack audits
   - shared reports

## Avoid In V1

- paywalling the whole app
- collecting emails before users can try the tool
- selling automatic cancellation
- asking for bank or inbox access

## Positioning

Free app:

> Audit your AI tools and creator subscriptions locally.

Paid support pack:

> Extra templates, preset packs, and monthly review workflows for creators who want a more structured checkup.
