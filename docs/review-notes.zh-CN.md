# 二轮审查记录

这次审查重点放在中文版本、PWA 更新、导入边界和手机体验。

## 已发现并处理的问题

### 1. UI 全部硬编码英文

问题：页面、按钮、表单、移动端导航、建议原因、提醒中心文案都是英文，中文用户理解成本高。

处理：新增 i18n 层，支持英文和中文切换。内部数据枚举仍保持英文，展示层负责翻译。

### 2. 建议原因只能输出英文

问题：规则引擎只返回英文字符串，中文 UI 只能显示英文建议。

处理：给规则引擎增加 `reasonCodes`，展示层根据语言生成对应文案。

### 3. 日历/邮件/短信提醒内容只有英文

问题：即使 UI 中文，生成的提醒标题和正文仍是英文。

处理：提醒生成函数增加语言参数，中文模式下生成中文标题、正文和短信内容。

### 4. 中文文档缺失

问题：README 和 docs 都是英文，不利于中文用户理解产品边界。

处理：新增 `README.zh-CN.md` 和中文 docs。

### 5. PWA manifest 只有英文

问题：手机添加到主屏幕后名称仍是英文。

处理：manifest 名称和描述改成中英双语可读。

## 仍然保留的设计选择

- 工具分类、计费周期等内部值仍使用英文枚举，避免破坏已有 JSON 备份。
- 默认币种仍是 USD，因为产品当前面向海外创作者平台和工具订阅。
- 中文版是同一个应用内切换，不单独维护一套中文代码。
