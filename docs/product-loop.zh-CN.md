# 产品使用回路

Creator Stack Checkup 的第一版不是复杂财务软件，而是一个低摩擦的“订阅体检”工具。

## 核心回路

1. 用户打开网页，不注册、不登录。
2. 用户添加自己正在付费的创作者工具。
3. 页面立即算出每月支出、年化成本、30 天内续费金额和潜在节省金额。
4. 规则引擎给每个工具打标签：保留、复盘、降级、可取消。
5. 用户对快续费或可疑工具生成提醒。
6. 用户每月回来更新使用频率和业务价值，再做一次体检。

## 为什么这样设计

目标用户通常不是想记账，而是想快速知道：

- 我每月到底花了多少钱？
- 哪些工具重复了？
- 哪些工具快续费了？
- 哪些工具可能该取消或降级？
- 我不用注册账号能不能马上用？

因此第一版只做本地数据和即时反馈，不做账号系统、云同步或自动扣费分析。

## 推荐的用户路径

第一次使用：

1. 点击“载入示例”理解产品。
2. 删除示例数据。
3. 添加 5 到 15 个真实订阅。
4. 看智能建议。
5. 给 30 天内续费的工具添加日历提醒。
6. 导出 JSON 做一次本地备份。

月度复盘：

1. 打开 PWA。
2. 更新使用频率和业务价值。
3. 查看可取消、可降级和重复分类。
4. 处理快续费订阅。
5. 导出新备份。

## 第一版边界

第一版不负责替用户做决定，只负责把成本和风险显性化。自动取消、银行导入、邮箱扫描、云端提醒都属于未来版本。
