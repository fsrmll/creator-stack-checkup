# Product Loop

Creator Stack Checkup is not a spreadsheet replacement. It is a short subscription checkup flow.

## Core Loop

1. User opens the website.
2. User adds a few paid creator tools.
3. The dashboard immediately shows monthly burn, annualized cost, possible savings, and upcoming renewals.
4. The rules engine marks tools as `Keep`, `Review`, `Downgrade`, or `Cancel Candidate`.
5. User sets a calendar/mail/SMS reminder for anything that needs review.
6. User returns monthly to repeat the checkup.

## Intended Audience

- AI tool users
- solo creators
- digital product sellers
- designers and writers
- indie builders
- people paying for several small tools that add up

## Success Criteria

- A first-time user can add 3 tools in under 2 minutes.
- A user can understand their monthly and yearly tool burn without reading documentation.
- A user can create a cancellation or review reminder without creating an account.
- The app remains useful even with no backend.

## Product Principle

The app should answer one practical question:

> What am I paying for, what overlaps, and what should I review before it renews?
